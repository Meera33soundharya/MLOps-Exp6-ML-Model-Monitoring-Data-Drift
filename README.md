# ML Model Monitoring and Data Drift

A small, reproducible MLOps experiment that creates reference and production-like
data, tests for numerical and categorical feature drift, writes a JSON summary
and HTML report, and exposes the results to Prometheus and Grafana.

## Project files

- `generate_data.py` creates deterministic sample CSVs in `data/`.
- `drift_detection.py` compares the reference and current data using the
  two-sample Kolmogorov-Smirnov test for numeric features and a chi-square test
  for categorical features.
- `drift_summary.json` and `drift_report.html` are generated by the detector.
- `metrics_server.py` periodically reruns the checks and exports Prometheus
  metrics on port 8000.
- `prometheus.yml` configures a local Prometheus scrape target.
- `grafana_dashboard.json` is a dashboard definition for the exported metrics.

## Requirements

- Python 3.10 or newer
- Prometheus and Grafana are optional, and are only needed for the dashboards.

Install the Python dependencies:

```bash
python -m pip install -r requirements.txt
```

## Generate data and run a drift check

From the project directory:

```bash
python generate_data.py
python drift_detection.py
```

The generated CSVs are `data/reference.csv` and `data/current.csv`. The
detector writes `drift_summary.json` and `drift_report.html` to the project
directory and prints the summary to the terminal. A feature is marked as
drifted when its p-value is below the default significance threshold of 0.05.

Useful options:

```bash
python generate_data.py --rows 1000 --output-dir data
python drift_detection.py --reference data/reference.csv --current data/current.csv --threshold 0.01
```

## Export metrics

Start the monitoring process in a separate terminal:

```bash
python metrics_server.py --port 8000 --interval-seconds 30
```

The process runs a check immediately, then repeats it every 30 seconds.
Prometheus metrics are available at `http://localhost:8000/metrics`.

To scrape the local exporter, start Prometheus with this project's config:

```bash
prometheus --config.file=prometheus.yml
```

In Grafana, add the Prometheus data source and import `grafana_dashboard.json`.
The dashboard displays the overall drift flag, the number of drifted features,
and per-feature drift and p-value series.

## Metrics

- `ml_data_drift_detected`: 1 if any feature is drifted, otherwise 0.
- `ml_drifted_features_total`: number of drifted features in the latest check.
- `ml_current_rows`: number of rows in the latest current-data sample.
- `ml_feature_drift_detected`: drift flag per feature and statistical test.
- `ml_feature_drift_p_value`: p-value per feature and statistical test.

The sample generator deliberately shifts some current-data distributions so
that a drift check has positive findings to report. Replace the sample CSVs
with compatible data to monitor a different schema.
